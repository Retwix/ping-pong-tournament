Accueil — le tableau de bord vivant
Refonte de l'écran d'accueil selon le brief « Live hero + 2 colonnes ». Un coup d'œil répond à trois questions : qui joue maintenant, qui est en tête, qu'est-ce qui vient de se passer. Barre de navigation persistante, hero live contextuel, colonne principale (tournois + résultats) et rail latéral (top joueurs + séries). Frames : desktop actif · desktop au repos · thème sombre · mobile · nouvel espace (vide). Tokens Recovr.
